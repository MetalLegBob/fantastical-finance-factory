# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately to **drfraudsworth@gmail.com**. This is the same contact embedded in
each program's on-chain `security.txt`. Please include:

- the affected program and program ID
- a description of the issue and its impact
- steps or a proof of concept to reproduce it

The full security policy is at <https://docs.fantasticalfactory.com/security/security-policy>.

## Scope

The seven programs in this repository, as deployed on Solana mainnet-beta (program IDs are listed in the
[README](README.md#programs)).
